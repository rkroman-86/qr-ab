Gestion qrbc

Rappels automatiques

Chaque jour à 8 h–9 h (heure de Paris), un e-mail part aux clients concernés, dans la langue de leur éditeur, avec le bouton de paiement et le lien vers leur page : essai J-7 et J-1 · abonnement J-30, J-7 et J-1 · jour de la mise en pause · J+30 · J+80 (suppression annoncée). À J+90, le compte apparaît « à supprimer » dans l’onglet Clients : la suppression reste manuelle.

    Codes promo

    Le client qui saisit un code actif à l’inscription a 14 jours d’essai + les jours du code ; le paiement n’est demandé qu’après. Le code reste noté sur sa fiche (onglet Clients), même si vous le désactivez ensuite. Lien à donner à un apporteur : qrbc.app/?promo=CODE (le code est prérempli).

    Intelligence artificielle (Anthropic)

    …

    Sert aux textes, aux pictogrammes et aux descriptions des images de fond. La clé est vérifiée auprès d’Anthropic (sans consommer de crédit), puis rangée chiffrée : elle ne sera plus jamais affichée. Créez-la dans la Console Anthropic › API keys.

    Paiements en ligne (Stripe)

    …

    La clé est vérifiée auprès de Stripe, puis rangée chiffrée : elle ne sera plus jamais affichée. Le webhook et le taux de TVA à 20 % sont créés automatiquement.

    Tarifs et quotas IA

    Appliqué partout (appli, offres, messages, paiements) dans la minute. Les abonnements en cours gardent ce qui a déjà été payé ; les quotas restants suivent les nouvelles valeurs.

    E-mails (Resend)

    …

    Sert à envoyer les liens « mot de passe oublié ». Le domaine qrbc.app doit être ajouté et vérifié dans Resend. La clé est rangée chiffrée.
